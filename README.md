# data-anonymizer

![Python](https://img.shields.io/badge/Python-3-3776AB?logo=python&logoColor=white)
![GUI](https://img.shields.io/badge/GUI-Tkinter-informational)
![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20Linux%20%7C%20macOS-lightgrey)

**Приложение для обезличивания персональных данных** в таблицах. Загружает Excel или JSON, помогает найти столбцы с персональными данными и заменяет их одним из пяти методов. Все действия пишутся в журнал аудита.

## Возможности

- **Загрузка и сохранение** таблиц: Excel (`.xlsx`, `.xls`) и JSON.
- **Автоматический поиск** столбцов с персональными данными и **анализ рисков**.
- **Пять методов обезличивания** выбранных столбцов (таблица ниже).
- **Восстановление** исходных данных для обратимых методов (шифрование и псевдонимизация) по паролю.
- **Защита от повторной обработки** — один и тот же столбец нельзя обезличить дважды по ошибке.
- **Учётные записи и роли** `admin` и `user`.
- **Журнал аудита** действий пользователей в SQLite (`audit.db`) и лог-файл `data_anonymizer.log`.

## Методы обезличивания

| Метод | Результат | Обратимость |
|---|---|---|
| Шифрование | каждое значение шифруется паролем (Fernet; ключ из пароля через PBKDF2-HMAC-SHA256, 100 000 итераций) | да, по паролю |
| Хеширование | SHA-256 со случайной солью | нет |
| Обобщение | числа заменяются диапазонами (`0-10`, `20+`, `100+`, `1000+`…), даты укрупняются | нет |
| Рандомизация | значения случайно перемешиваются внутри столбца | нет |
| Псевдонимизация | каждому уникальному значению присваивается идентификатор вида `ANON_000001` (префикс настраивается); таблица соответствий шифруется паролем | да, по паролю |

Пустые значения при обработке остаются пустыми.

## Требования

- Python 3 с Tkinter. В Windows и macOS Tkinter входит в стандартную поставку, в Linux нужен пакет `python3-tk`.
- Библиотеки из `requirements.txt`: `pandas`, `openpyxl`, `cryptography`.

## Установка и запуск

```bash
git clone https://github.com/woqowieowww/data-anonymizer.git
cd data-anonymizer
pip install -r requirements.txt
python data_anonymizer.py
```

При первом запуске рядом с программой создаются файлы `audit.db` и `data_anonymizer.log`. Они не попадают в репозиторий (см. `.gitignore`).

## Как пользоваться

1. Войдите под своей учётной записью.
2. Загрузите таблицу (Excel или JSON).
3. Выберите столбцы вручную или нажмите автоматический поиск персональных данных.
4. По желанию запустите анализ рисков.
5. Выберите метод обезличивания.
6. Сохраните результат в Excel или JSON.
7. Журнал аудита покажет, кто и что сделал с каким файлом.

## Метаданные для восстановления

Чтобы обратимые методы можно было отменить и после перезапуска программы, при сохранении записывается служебная информация: метод, соль и зашифрованная таблица соответствий (для псевдонимизации). Сам пароль нигде не сохраняется.

| Формат | Где лежат метаданные |
|---|---|
| Excel | рядом с таблицей, в файле `<имя>_meta.json` |
| JSON | внутри файла, в поле `metadata` |

При загрузке файла программа сама подхватывает метаданные. Не теряйте `_meta.json` вместе с обезличенной таблицей: без него восстановление невозможно.

## Безопасность

> [!WARNING]
> При первом запуске создаются учётные записи по умолчанию — `admin` и `user`. Их пароли указаны в исходном коде. Это демонстрационные данные: для реального использования смените пароли и замените хранение паролей на соль с медленным алгоритмом (bcrypt, scrypt или Argon2).

Если вы потеряете пароль шифрования или псевдонимизации, данные восстановить не получится.
